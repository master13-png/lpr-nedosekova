# ЛПР № 9 — результаты наблюдений

## Параметры

- Студент: Недосекова Александра Ивановна
- Группа: Ис-24-22б
- Вариант: 14 — «Аптека»
- Код занятия: F1-FUTI, J8-LAIP
- База данных: `lpr_nedosekova`
- `PER_PAGE=5`, `MIN_LEN=4`, `STR_LEN=142`, `SEED=26`, `PARENTS=5`
- `ON_DELETE=restrict`, `SORT=created_at DESC` (сначала новые)

Для совместимости с каталогом ЛПР № 8 сохранено его существовавшее поле `code`.
Формат `AA-0000` использует параметры записи ЛПР № 8: две заглавные латинские
буквы и четыре цифры. Поля варианта 14 при этом сохранены.

## Наблюдение 1. База данных и миграции

Подключение выполнено через `MySQL-8.4`, версия сервера — **8.4.7**.
До запуска миграций целевая схема `lpr_nedosekova` была пустой. После выполнения
трёх стандартных миграций Laravel в ней стало **9 таблиц**: `users`,
`password_reset_tokens`, `sessions`, `cache`, `cache_locks`, `jobs`,
`job_batches`, `failed_jobs` и `migrations`. Это таблицы штатных миграций
Laravel, а не таблицы предметной области.

После миграций варианта в целевой схеме **11 таблиц**: девять стандартных и
`manufacturers`, `medicines`. `php artisan db:show` также показывает суммарную
статистику всего локального MySQL-сервера (33 таблицы до миграций проекта,
42 после стандартных и 44 после миграций предметной области); принадлежность
таблиц проекту проверялась отдельно по `TABLE_SCHEMA = 'lpr_nedosekova'`.

- Производители: **5**

  произошло; после проверки осталось 5 производителей и 26 препаратов.

## Наблюдение 4. Проблема N+1

Проверка выполнена для страницы из пяти препаратов через журнал SQL-запросов
Laravel:

| Вариант | Запросы | Состав |
|---|---:|---|
| Без `with()` | **7** | подсчёт страниц + список + по запросу производителя на каждую из 5 записей |
| С `with('manufacturer')` | **3** | подсчёт страниц + список + один запрос производителей |

Для этой страницы число запросов без eager loading: `2 + PER_PAGE = 7`;
с eager loading: `2 + 1 = 3`.

## Наблюдение 5. Валидация

Ошибки проверены отправкой HTTP-запросов в Feature-тестах. В тестах
использовались отдельная SQLite in-memory база и фабрики; база MySQL проекта
не изменялась.

| Поле | Введённое значение | Результат |
|---|---|---|
| `name` | `Нос` (3 символа) | «Название должно содержать не менее 4 символов.» |
| `manufacturer_id` | `PHP_INT_MAX` (несуществующий ID) | «Выбранный производитель не существует.» |
| `code` | `md-01` | Ошибка формата: код должен содержать две заглавные буквы и четыре цифры |
| `code` | `QA-0001`, уже занятый другим препаратом | «Такой код препарата уже используется.» |
| `price` | `-1` | «Цена должна быть больше нуля.» |
| обязательные поля | пустой запрос | Ошибки обязательных полей; введённое значение названия сохраняется через `old()` |
